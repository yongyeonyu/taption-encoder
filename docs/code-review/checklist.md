# 审查清单

**怎么用**

- 作者：开 PR 前先过 A 段和所属风险级别的段落，把勾选结果贴进 PR 描述。
- 审查者：对着 diff 从上往下走。任何一项打不了勾，就留一条带级别的评论（`blocker` / `major` / `minor` / `nit`）。
- 全部打勾不等于没问题。清单是为了不漏，不是为了替代判断。

标记说明：**[T1]** 编解码 / 编码 / 文件写入必查 · **[T2]** 功能改动必查 · **[T3]** 低风险改动也查

---

## A. 变更本身 [T3]

- [ ] 能用一句话说清这个 PR 解决什么，且和标题一致
- [ ] 改动范围与描述相符，没有夹带无关重构
- [ ] 变更 ≤ 400 行；超出时已说明理由或已拆分
- [ ] 新行为有测试，或已说明为何无法测试
- [ ] 没有调试代码、注释掉的代码块、临时文件、`print(`

## B. 正确性 [T3]

- [ ] 边界条件想过：空输入、单文件、超大文件、非标准分辨率、0 时长
- [ ] 失败路径完整：状态回滚、临时文件清理、界面不停在 loading
- [ ] 没有用 `try?` 吞掉会导致静默失败的错误
- [ ] 没有新增强制解包、`as!`、`try!`
- [ ] 魔法数字有出处（钳制范围、码率、超时、重试次数）
- [ ] 单位正确：秒 vs 毫秒、字节 vs 比特、pt vs px
- [ ] 取消与中断能正确传播
- [ ] 幂等：重复点击、重复导入不会产生重复结果

## C. 并发 [T2]

- [ ] `@MainActor` 隔离没有被绕过
- [ ] 每个 `@unchecked Sendable` 都有书面理由
- [ ] `Task` 有取消路径，`onDisappear` / `deinit` 后不会写失效状态
- [ ] 跨线程对象确实线程安全（`CVPixelBuffer` 是；`AVAssetWriter`、`VLCMediaPlayer` 不是）
- [ ] 共享可变状态有保护（actor / lock / main actor）
- [ ] 主线程上没有重活（解码、文件 IO、格式探测、缩略图生成）

## D. 资源与内存 [T2]

- [ ] security-scoped 访问 `start` / `stop` 成对，用 `defer`
- [ ] 文件句柄、管道、`CVPixelBufferPool` 在失败路径也释放
- [ ] 闭包没有意外的 self 强引用循环
- [ ] 大量像素缓冲不会同时驻留（尤其是批量转码）

## E. 编解码与媒体 [T1]

- [ ] 容器 / 编解码路由的改动有 fixture 证据
- [ ] 硬件路径与软件路径都考虑过，回退有测试
- [ ] 输出能被系统播放器打开——**真机验证**，不只是模拟器
- [ ] 音视频时长、帧数对齐
- [ ] 元数据在转码后仍正确：旋转、HDR、色彩空间、alpha
- [ ] 失败时不留下半成品文件
- [ ] FFmpeg 子进程：退出码检查、stderr 被消费、超时可杀

## F. 接口与兼容 [T2]

- [ ] 公开类型 / 方法签名变更，扩展 target 也编译通过
- [ ] `UserDefaults`、文件格式、书签的持久化格式向后兼容
- [ ] 新增依赖必要，许可证合规（本项目含 LGPL 解码桥）
- [ ] 删除的代码没有被其他 target 引用

## G. 界面与体验 [T2]

- [ ] 空 / 加载 / 错误 / 成功四种状态都处理了
- [ ] 深色模式、动态字体、横竖屏、宽屏（短边 ≥ 700pt）都不破版
- [ ] 文案与既有术语一致（Source / Output / Convert）
- [ ] 无障碍标签存在，且不是简单复述可见文案

## H. 安全与隐私 [T1]

- [ ] 没有把用户媒体外发
- [ ] 新增权限 key 有用途说明文案
- [ ] 新增 required-reason API（`UserDefaults`、文件时间戳等）已同步 `PrivacyInfo.xcprivacy`
- [ ] 日志不含用户内容（文件路径可接受，画面 / 元数据内容不可）

## I. 可读性 [T3]

- [ ] 命名说清"是什么"，而不是"怎么做的"
- [ ] 注释解释"为什么"，不是复述代码
- [ ] 新逻辑没有被塞进已经超长的文件（`HomeViewModel` 7,296 行、`CodecRoutePlannerTests` 18,266 行）
- [ ] 删掉的复杂度没有换个地方长回来

## 一票否决（不必逐项，看到即拦）

| 情况 | 为什么 |
| --- | --- |
| 新增测试文件未注册到 `project.pbxproj` | 测试静默不执行，"测试通过"变成假信号 |
| 编码失败后仍报告成功 | 用户拿到损坏文件 |
| `finishWriting` / `cancelWriting` 缺失 | 半成品文件 + 资源泄漏 |
| 用 `@unchecked Sendable` 压掉并发警告且无理由 | 数据竞争，难复现、难定位 |
| 新增 required-reason API 未同步 `PrivacyInfo.xcprivacy` | 提交审核被拒，且发现时已临近发版 |
| 用户视频内容被上传或外发 | 违背产品承诺 |
| 新增 `print(` 或吞掉错误的 `try?` | 线上问题无法定位 |
| 直接向 `main` 推送 | 绕过全部闸门 |
