FFmpeg LGPL Decode Bridge

This application uses libraries from the FFmpeg project under the GNU Lesser
General Public License version 2.1 or later. It includes a source-built decode
bridge for selected
legacy and ProRes RAW input decoding. The bridge is built from FFmpeg 8.1.1
source code with GPL and nonfree components disabled.

Enabled surface in this BOKKI Encoder bridge:
- Libraries: avformat, avcodec, avutil, swresample, swscale
- Demuxers: vc1, avi, mov, dv, asf, rm
- Video decoders: vc1, vc1image, y41p, rawvideo, prores_raw, dvvideo, h263, mjpeg, mpeg4, msmpeg4v3, msrle, smc, r10k, r210, rv10, rv20, snow, utvideo, wmv2
- Audio decoders: pcm_s16le, mp3, aac, ac3, wmav2
- Bridge outputs: direct NV12 video frames for even dimensions, BGRA fallback frames for odd dimensions, and swresample-converted packed signed 16-bit PCM audio frames
- Parsers: ac3, vc1, mpeg4video
- Protocol: file

Build policy:
- No FFmpeg command-line executable is bundled.
- No downloaded codec plugin or runtime-downloaded executable is used.
- No --enable-gpl or --enable-nonfree configure flag is used.
- H.265 / HEVC MP4/MOV output remains handled by BOKKI Encoder's AVAssetWriter path.
- Supported bridge audio is written by AVAssetWriter as AAC in MP4/MOV, or as
  a supported Apple-native audio output selected for MOV.
